# Instruções para continuar

Leia primeiro `docs/HANDOFF.md`. Este é um guia de suporte para colaboradores da Universidade Brasil.

- Pedido explícito do proprietário: NÃO publicar no OpenAI Sites nem em outra hospedagem. Entregar localmente e enviar alterações ao GitHub `arthur-amancio/Guia-Orienta-o-UB`.
- Validar antes de commit/push. Não confundir push ao GitHub com deploy. Não usar o remoto de hospedagem nem obter credenciais do Sites.
- Usar capturas REAIS de `https://suporte.ub.edu.br/Helpdesk`. Nunca gerar ou reconstruir telas do sistema com IA.
- Excluir nomes, iniciais, e-mails, identificação da conta e dados de chamados das capturas ANTES de versionar. Não enviar capturas brutas ao GitHub. Não basta esconder dados via CSS.
- Navegar no portal só para consulta; não enviar chamados, reservas, mensagens ou mudar configurações para produzir exemplos.
- Preservar conteúdo verificado e distinguir orientações gerais de comportamentos observados.
- Após mudanças, atualizar o handoff de forma curta: arquivos relevantes, validação, limitações e próximo passo. Não registrar tokens, senhas ou dados do colaborador.
- Não atualizar dependências em massa nem usar `npm audit fix --force` como manutenção incidental.

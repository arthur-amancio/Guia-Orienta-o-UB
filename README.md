# Guia do Colaborador — Universidade Brasil

Guia visual para o portal de suporte UB com capturas reais, marcações numeradas, instruções de preenchimento e ampliação das imagens.

## Desenvolvimento

Requer Node compatível com `package.json`. Execute `npm ci` e `npm run dev`. Para validar, use `npm run build` e `npm run lint`.

## Continuação por IA

Leia `AGENTS.md` e `docs/HANDOFF.md` antes de editar. Não publicar em hospedagem: o fluxo autorizado é local → validação → commit → GitHub.

As telas foram consultadas em 15/09/2026 e podem variar por unidade/perfil. A identificação da conta foi excluída dos recortes. Nenhum chamado foi enviado para criar este material.
